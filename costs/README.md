# WAS – إدارة تكاليف التقاوي

تطبيق هاتف عربي لإدارة تكاليف الحواشات في جميع المحاصيل والمواسم التعاقدية.

## التشغيل
- افتح https://tabbby124-glitch.github.io/wase-agri/costs/ من Chrome.
- من قائمة Chrome اختر تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
- البيانات تُحفظ محلياً وتظل متاحة دون إنترنت بعد تحميل التطبيق.
- سجّل الدخول إلى حساب WAS السحابي من التطبيق الرئيسي، ثم افتح صفحة التكاليف لاستخدام المزامنة.

## الوظائف الحالية
- إنشاء المواسم وتحديد الموسم النشط.
- تسجيل الحواشات: رقم الحواشة، اسم المزارع، المحصول، المساحة، القرية ورقم العقد.
- البحث برقم الحواشة أو اسم المزارع أو المحصول.
- ملف مستقل لكل حواشة يعرض كل المصروفات ونصيب الحواشة وتكلفة الفدان.
- مصروف فردي لحواشة واحدة.
- مصروف مشترك موزع حسب المساحة أو بالتساوي أو بمبالغ يدوية، مع التحقق من أن مجموع التوزيع يساوي قيمة المصروف.
- تقارير الحواشات، تصدير CSV المتوافق مع Excel، ونسخ احتياطي JSON.
- مزامنة ورفع واستعادة بيانات المواسم والحواشات والمصروفات من Supabase.

## قاعدة البيانات
- المشروع: `was-agri-cloud` في `eu-central-1` (Frankfurt).
- الجداول: `cost_seasons`, `cost_fields`, `cost_entries`, `cost_allocations`.
- تم تفعيل RLS وسياسات عضوية المؤسسة، مع مفاتيح خارجية تمنع ربط سجلات من مؤسسات مختلفة.
- ملف المخطط: `../supabase/cost_management_schema.sql`.

## Android
- ملفات التطبيق موجودة أيضاً داخل `www/costs/` لاستخدامها في نسخة Capacitor.
- إعداد GitHub Actions لبناء APK تجريبي موجود في `.github/workflows/android-apk.yml`.
- ملف APK لا يُعد جاهزاً حتى تنجح مهمة GitHub Actions ويظهر artifact باسم `WAS-Android-debug`.

## ملاحظات
- المزامنة السحابية تحتاج حساباً موثقاً في WAS؛ تسجيل الدخول المحلي التجريبي وحده لا يكفي.
- عند الاستعادة من السحابة، تُستبدل بيانات الجهاز بعد تأكيد المستخدم؛ يوصى بتصدير نسخة احتياطية قبلها.
