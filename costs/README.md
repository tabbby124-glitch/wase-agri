# WAS – إدارة تكاليف التقاوي

نسخة أولية للهاتف لإدارة الحواشات والمصروفات على مستوى الموسم.

## التشغيل
- افتح https://tabbby124-glitch.github.io/wase-agri/costs/ من Chrome.
- من قائمة Chrome اختر تثبيت التطبيق / إضافة إلى الشاشة الرئيسية.
- البيانات في هذه النسخة محفوظة محلياً على الجهاز، وتعمل الواجهة دون اتصال بعد أول تحميل.
- استخدم إعدادات النسخ الاحتياطي لتصدير JSON واستعادته.

## الوظائف
- تسجيل المواسم والحواشات بجميع المحاصيل.
- البحث باسم المزارع أو رقم الحواشة.
- مصروف فردي لحواشة واحدة.
- مصروف مشترك موزع بالتساوي أو حسب المساحة أو بمبالغ يدوية.
- تقرير تكاليف الحواشة، تكلفة الفدان، وتصدير CSV.

## قاعدة البيانات
ملف `../supabase/cost_management_schema.sql` مسودة مخطط Supabase. لا تطبقها قبل فحص جداول المؤسسة الحالية والتأكد من أعمدة `organization_members`.

## الحالة
هذه نسخة واجهة أولية محلية وليست بعد نظام مزامنة سحابية متعدد الأجهزة أو APK مستقل. يلزم إكمال تهيئة Supabase، واختبار RLS والمزامنة، ثم بناء Android عبر Capacitor.
