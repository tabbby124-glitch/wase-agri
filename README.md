# واس الزراعية — WAS Agri

تطبيق ويب عربي لإدارة الحقول والعمليات الزراعية والإنتاج والحصاد والتكاليف، مصمم للاستخدام من الهاتف.

**التطبيق المنشور:** https://tabbby124-glitch.github.io/wase-agri/

## الوظائف الحالية
- إدارة الحقول والمساحات والأصناف وتواريخ الزراعة.
- تسجيل العمليات الزراعية: الحرث والزراعة والري والتسميد والرش والحصاد.
- تسجيل الحصاد بالأوزان القابلة للتعديل للشوال والصندوق وحساب الإنتاج بالطن.
- تقارير الحقول والإنتاجية والتكاليف والأرباح.
- واجهة عربية وإنجليزية ووضع ليلي.
- تخزين محلي في المتصفح مع تصدير واستعادة نسخة احتياطية.
- صور العمليات محفوظة في IndexedDB على الجهاز.

## التثبيت والعمل دون اتصال
يدعم التطبيق التثبيت كتطبيق ويب (PWA) عبر Chrome:
1. افتح التطبيق واتصل بالإنترنت لتحميل الملفات أول مرة.
2. من قائمة Chrome اختر **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
3. بعد تحميل ملفات التطبيق يمكن فتحه دون اتصال. بعض الخطوط والوظائف الخارجية قد تحتاج إلى الإنترنت.

## النسخ الاحتياطي
من تبويب **التقارير** اختر **نسخة احتياطية**. النسخ الجديدة تتضمن بيانات التطبيق وصور العمليات المحفوظة محلياً. عند الاستعادة سيطلب التطبيق تأكيداً لأن البيانات الحالية ستُستبدل. النسخ القديمة التي لا تحتوي على الصور يمكن استعادتها للبيانات فقط.

## تنبيه أمني مهم
- البيانات محفوظة محلياً في المتصفح وليست قاعدة بيانات سحابية مشتركة.
- حسابات الدخول الحالية محلية، وكلمات المرور ليست محمية بخادم مصادقة؛ لا تستخدمها كحماية أمنية لبيانات تجارية حساسة.
- لا توجد مزامنة مركزية موثوقة بين الأجهزة حالياً. يلزم Backend وقاعدة بيانات ومصادقة وصلاحيات خادمية لتحقيق ذلك بأمان.
- احتفظ بنسخة احتياطية دورية، ولا تمسح بيانات المتصفح قبل تصديرها.

## التقنية
HTML وCSS وJavaScript، مع LocalStorage للبيانات وIndexedDB لصور العمليات، وService Worker للتخزين المؤقت والعمل دون اتصال.
